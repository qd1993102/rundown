# Web 日报移动端重构与图片保存

- **日期**: 2026-07-28
- **类型**: feature / refactor

## 背景与动机

日报详情和列表原先以桌面布局为基础，再用单个 `max-width` 断点压缩。手机上导航、主题、日期和
日报内容虽然能够显示，但触控尺寸、信息顺序和卡片换行不是默认设计目标；日报也只能在页面中查看，
缺少便于保存到相册或分享的入口。

## 方案选择

页面样式改为移动端基础规则，桌面端通过 `min-width:641px` 增强。普通内容继续使用 Grid、Flex
和文档流，避免依赖绝对定位或固定画布宽度；关键数据放在 AI 长文本之前，手机用户打开页面后先看到
恢复与训练准备状态。

图片导出选择浏览器 Canvas，而不是 CDN 版 DOM 截图库或服务端 Playwright：

- 不增加外部前端依赖，也不要求线上容器安装 Chromium；
- 直接复用已经鉴权获取的日报 JSON，不需要增加 API；
- 图片只在浏览器内生成，避免将训练和健康数据传给第三方；
- 移动端用 Web Share API 接入系统保存/分享，桌面及不支持环境回退为 Blob 下载。

## 实现步骤

1. 重构 `chat.html` 与 `reports.html` 的工具栏、计划、指标、训练和列表卡片布局。
2. 将主题按钮、日期输入和主要操作调整到适合触控的尺寸，并增加键盘焦点和减少动画偏好支持。
3. 在日报详情增加保存操作、`aria-live` 状态和浏览器内日报海报绘制器。
4. 按当前主题绘制日期、恢复指标、身体指标、AI 洞察、训练明细和负荷摘要，输出 2 倍像素密度 PNG。
5. 支持系统文件分享、下载回退、用户取消和错误恢复。
6. 增加模板契约测试并同步 README、模块设计、数据流、Web 部署设计和 CHANGELOG。

## 遇到的问题与解决

- 训练计划条虽然 CSS 已声明 Grid，但渲染脚本仍写入 `display:flex`，覆盖了移动端 2×2 规则；
  将运行时显示值改为 `grid`，桌面四列由媒体查询控制。
- 系统分享属于用户可取消操作；取消时不显示错误，仅恢复按钮并提示“已取消保存”。
- 导出图片不复刻 DOM 截图，而是按结构化数据绘制稳定海报，避免页面高度、浏览器缩放和外部字体资源
  让截图结果不可预测。

## 验证

- 模板脚本通过 Node 语法解析；模板契约测试覆盖移动端断点、触控尺寸、Canvas、Web Share 与下载回退。
- 390×844 浏览器视口验证详情页和列表页，`scrollWidth` 与 390px 视口一致，无横向滚动。
- 导航、主题按钮、生成和保存操作均达到 44px 触控高度；计划条为两列。
- 保存操作成功生成图片并进入系统分享流程；取消分享后页面显示可恢复状态，浏览器控制台无错误。

## 统一导航后续修正

首轮重构后，日报详情与列表使用新的宽幅顶部导航，而同步和我的页面仍保留旧桌面胶囊导航；四页
虽然入口名称相同，但结构、尺寸、断点和主题工具位置并不一致，也不符合手机应用常见的主导航模型。

后续将 `sync.html`、`chat.html`、`reports.html`、`profile.html` 统一为同一套合同：

- 手机端固定底部三项导航，使用一致的 SVG 图标、文字、54px 触控高度和主题当前态；
- 内容容器预留导航高度及系统底部安全区，底部栏作为平台级 chrome 使用受控的 `position:fixed`；
- 手机顶部仅保留 neurun 标识与紧凑主题工具；“我的”页退出登录移动到账号卡片内；
- 641px 以上恢复静态顶部横向导航，顺序和当前态语义保持不变。

390×844 视口下三页导航均为 366×68px、距底部 10px，页面 `scrollWidth` 与视口一致；通过导航
实际完成同步页到日报页、再到我的页面的切换，每页只有一个 `aria-current="page"`。1024px 视口
确认导航切换为 `position:static`、横向图文排列，浏览器控制台无错误。

## 日报列表评分换行修正

统一导航后的移动端列表规则曾将 `report-scores` 设置为跨越整个 Grid，导致评分整体落到第二行，
320px 视口下卡片内容高度约 109px。修正后列表使用“44px 日期 / 可收缩摘要 / 固定评分”三列：

- 训练标题和洞察只在摘要列内截断；
- 两个评分使用 36px 最小宽度、8px 间距及 `nowrap`，不参与换行；
- 641px 以上恢复 56px 日期列、44px 评分和 16px 间距。

320×720 视口验证卡片内容高度约 44px，两个评分与日期、摘要处于同一行，页面 `scrollWidth`
仍等于 320px；新增模板契约测试锁定三列布局、摘要省略和评分不换行规则。
