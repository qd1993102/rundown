# Bug: 日报详情在数据缺失时渲染空白“—”卡片（白块）

- **发现日期**: 2026-08-13
- **修复日期**: 2026-08-13
- **严重程度**: major
- **影响范围**: 日报详情页（/）的恢复与负荷模块；受限版/新用户（睡眠、恢复指标、负荷缺失）显示大量空白卡片

## 现象

登录 `qd1993102@126.com`（日报为受限版，睡眠/恢复/负荷均无数据）打开日报详情，
“查看数据依据：恢复、负荷与教练观察”区域出现多个空白卡片块：
- 睡眠 / 恢复评分 / 训练准备三张 Hero 卡显示 `—h`、`—/100`、`—`；
- HRV / 静息心率 / 身体电量 / 压力四张指标卡全部显示 `—`；
- 负荷卡显示 `1 / — / — / optimal`（无效的退化数据）。

有完整数据的用户（如 `qd1993102@gmail.com`）负荷卡也长期显示
`1.21 / — / — / optimal`：慢性负荷与急性负荷恒为空白。

## 根因

1. 前端 `dashboard.html` 用 `ld.acute_load` / `ld.chronic_load` 读取负荷，但后端字段名是
   `acute_load_7d` / `chronic_load_28d`，字段名不匹配导致慢性/急性负荷永远渲染为 `—`。
2. 数据缺失时模块照常渲染卡片并用 `—` 占位，没有隐藏逻辑，形成大量空白占位块；
   ACWR 在急性/慢性负荷都为 0 时回退为 1.0 + `optimal`，是无效退化值，不应展示。

## 修复方案

- 修正负荷字段名（`acute_load_7d`、`chronic_load_28d`）；
- 新增 `hasVal` 判定：无数据的模块卡片直接隐藏（`display:none`），整组无数据时隐藏整块区域；
- 负荷卡仅在急性或慢性负荷 > 0 时展示，避免无效 ACWR；
- “数据依据”折叠区整体为空时，`summary` 收拢为一行说明
  （“查看数据依据：当日睡眠、恢复与负荷数据暂缺（受限版）”），避免大片空白。

## 相关文件

- [docs/product/daily-report.md](../../docs/product/daily-report.md) — 验收标准补充：
  缺失维度不得渲染空白占位块
