# Bug: 高驰日报部分恢复指标卡片错位

- **发现日期**: 2026-08-13
- **修复日期**: 2026-08-13
- **严重程度**: minor
- **影响范围**: 日报详情页“查看数据依据：恢复、负荷与教练观察”；高驰等只返回部分恢复字段的报告

## 现象

高驰用户查看 2026-08-11 日报时，恢复区只有“恢复评分”可用，健康指标区只有 HRV、静息心率和压力可用。
缺失卡片虽然被隐藏，但“恢复评分”仍只占左侧三分之一，“压力”落在第二行左侧，出现孤立左对齐和空位。

## 根因

页面通过 `display:none` 隐藏无数据卡片，但 `.hero-grid` 固定为 3 列，`.metric-strip` 固定为移动端 2 列、
桌面端 4 列。Provider 返回部分字段时，可见项目数量变化，网格列数却不变，因此剩余卡片无法重新均分容器。

## 修复方案

- 渲染数据后统计恢复 Hero 与健康指标的实际可见数量，通过局部 CSS 变量更新网格列数；
- 恢复 Hero 按 1–3 个可见项均分；健康指标在移动端最多 2 列、桌面端最多 4 列；
- 保留原有缺项隐藏和整组隐藏规则，不改变高驰数据解析或数值。

- 运行 `pytest` 全量测试并确认零失败。
