# Bug: 单日同步日期选择器缺少上下文和快捷操作

- **发现日期**: 2026-08-03
- **修复日期**: 2026-08-03
- **严重程度**: minor
- **影响范围**: Web 同步页单日同步

## 现象

单日同步虽然已接入日历、相邻日期和快捷操作，但把原生日期字段藏在整块大面积目标卡下，视觉上像不可解释的按钮；用户难以区分当前同步目标、精确改选入口和日历选择的关系。

## 根因

同步页先有日历状态概览，后续迭代将日期字段作为透明覆盖层放在目标摘要上，导致展示和输入职责重新混在一起；日历状态也没有回写到单日目标摘要。

## 修复方案

以同步日历为主要选择器；单日卡拆为“本次同步目标”摘要和可见的“修改日期”字段。摘要展示完整日期、星期与当前同步/活动状态；前后一天和昨天/今天仍是轻量快捷操作。日历、精确字段与快捷操作共享唯一日期状态和日历高亮，未来日期禁用。

模板测试覆盖目标摘要、可见精确日期入口、相邻日期和今天快捷操作、未来日期上限；本地 8080 页面验证日历选择会同步到摘要。
