# Bug: 报告中心日期选择器未使用报告页样式与上下文

- **发现日期**: 2026-08-03
- **修复日期**: 2026-08-03
- **严重程度**: minor
- **影响范围**: Web 报告中心的日报与周复盘日期选择

## 现象

报告中心的日报和周复盘直接渲染裸 `input[type=date]`，没有与报告卡片、主题或当前选择的上下文整合，视觉层级混乱；用户也无法快速前后切换日期。

## 根因

报告中心的信息架构完成后二级页只保留了输入字段，已有 `gen-card` 样式没有承载实际日期控件，导致日期选择器绕开了页面的组件样式和状态模型。

## 修复方案

日报和周复盘都改为“范围摘要 + 可见修改日期 + 快捷操作”。日报摘要显示完整日期、已有报告和完整性状态；周复盘摘要显示自然周范围。两个入口共享各自唯一日期字段，并限制到用户本地今天。
