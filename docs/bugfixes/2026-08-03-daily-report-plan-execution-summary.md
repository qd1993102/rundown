# Bug: 日报缺少计划执行、目标进展与调整建议

- **发现日期**: 2026-08-03
- **修复日期**: 2026-08-03
- **严重程度**: major
- **影响范围**: 日报 Front Matter、报告详情、训练/同步联动

## 现象

日报只零散显示训练方案上下文，用户无法看到当天计划与已记录事实的关系、周目标进度、目标时间线或下一步调整建议。

## 根因

训练方案、活动汇总和恢复建议分别存在，日报没有一个日期锚定、可解释且不会写入方案的执行读模型。

## 修复方案

- 新增 `plan_execution_summary`，按报告日解析生效方案和当天课次。
- 固定汇总当天计划、活动事实、自然周跑步累计/周目标、阶段、目标日期及恢复建议。
- 同步状态未知写为待同步；跑步记录不被夸大为完整课次匹配；自行车等非跑步距离不计入跑量。
- 报告只提供训练或同步深链，不能批准调整、改写方案或宣称目标结果。

## 验证

- 有效方案的日报显示计划、事实、周跑量、阶段、目标时间线和建议。
- 同步未知只显示待同步，不判未执行；非跑步活动不计入周跑量。
- 运行完整 `pytest`，要求零失败。
