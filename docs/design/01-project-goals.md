## 1. 项目目标

构建一个 Python 命令行应用，通过 **garmy** 库对接 Garmin Connect 国际区 API，实现：

- 通过环境变量注入 Garmin 账号密码，完成认证
- 拉取运动活动列表（跑步、骑行、游泳等）
- 拉取日常健康指标（睡眠、心率、HRV、压力、身体电量等）
- 数据本地持久化（SQLite），支持离线查询与分析
- **记忆存储系统**：在原始数据之上构建结构化的运动知识库，包括每日综合报告、运动摘要、恢复摘要、竞技水平评估、训练目标与计划、执行跟踪、教练倾向与案例等
- **AI 教练工作流**：以报告中心为观察与决策建议主线，以训练系统为处方和执行落地；应用内以六条显式工作流完成日报、周复盘、方案与比赛策略，MCP Server 独立向 OpenClaw / Claude Desktop 提供训练事实和业务工具
- **训练方案执行**：训练系统消费目标、能力、运动习惯、恢复和报告结构化建议，持续展示今日训练、本周安排和长期阶段，允许用户提交现实约束、查看调整差异并在确认后生成新的方案版本
- **报告中心**：生成包含活动执行、运动表现、恢复、负荷、异常检测、目标进程和下一步建议的日报、周复盘与阶段复盘
- **Web 服务可运维性**：提供不依赖登录会话、用户数据或外部平台的存活检查端点，供负载均衡判断进程是否可接收 HTTP 请求
- **私有数据安全持久化**：平台 Token、应用账号、SQLite、备份与训练记忆统一写入当前 Web 服务用户可控的目录；认证完成后才能读取平台用户 ID，敏感目录和文件分别收紧为 `0700` 与 `0600`
- **同步进度可见性**：Web 用户通过逐月日历确认每一天是已同步、部分完成、失败、同步中还是未同步，并能从日历快速发起单日补同步
