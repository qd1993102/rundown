# 产品方案 — 应用账号（注册 / 登录 / 修改密码）

- **状态**: 已确认并实现
- **配套技术设计**: [design/04-modules.md](../design/04-modules.md) §4.6

## 用户问题

neurun Web 通过邀请码注册应用账号，用户凭邮箱和密码登录后查看日报、训练和同步数据。
账号密码可能泄露或遗忘，用户需要能安全地修改密码，而不是依赖管理员手工重置。

## 范围

- 邀请码注册：昵称、邮箱、密码（8–128 字符）。
- 邮箱 + 密码登录，HttpOnly Cookie 维持会话。
- 退出登录：只撤销当前会话，不删除账号或数据。
- 修改密码：登录用户在「我的」页自助修改，需验证当前密码。
- 不包含：忘记密码自助找回、账号删除、登录邮箱换绑、多设备会话管理。

## 流程

修改密码：

1. 已登录用户进入「我的」→「修改密码」卡片。
2. 输入当前密码、新密码、确认新密码。
3. 服务端校验当前密码与密码强度，成功后更新 scrypt 密码哈希。
4. 页面提示成功并清空输入框；下次登录使用新密码。

## 交互规则

- 新密码长度 8–128 字符，不要求大小写、数字或符号组合（与注册一致）。
- 当前密码错误：提示「当前密码错误」，不改变现有密码，不泄露账号是否存在。
- 新密码与当前密码相同：提示不允许。
- 两次输入的新密码不一致：前端直接拦截。
- 密码只保存随机盐 scrypt 哈希，服务端与日志不保存明文。
- 修改密码不撤销现有会话：会话基于 API Key Cookie，无多设备会话表。

## 验收标准

- 登录用户可在「我的」页完成修改密码，旧密码立即失效、新密码可登录。
- 未登录请求返回 `401`；无密码账号返回明确提示。
- 修改成功、当前密码错误、密码强度不足三种结果均有明确用户提示。
- 相关接口和页面行为已同步到技术设计与 README。
