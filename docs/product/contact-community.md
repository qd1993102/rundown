# 产品方案 — 联系我们与内测交流群

> 版本: v1.0 · 日期: 2026-07-29
> 状态: 已确认并实现
> 配套技术设计: [contact-community.md](../design/contact-community.md)

## 1. 背景与问题

neurun 当前没有稳定、易发现的站内联系入口。用户遇到数据同步、训练日报或账号问题时，
无法从正在使用的页面直接进入内测交流群。现有微信群二维码还会周期性失效，如果只把图片
硬编码到某一页，移动端识别和后续替换都会形成额外阻力。

## 2. 产品目标

- 已登录用户从任一 Web 页面都能发现“联系我们”入口。
- 桌面端可以直接扫码，移动端可以保存二维码后从微信相册识别。
- 二维码更新不改变入口位置、文案或用户操作路径。
- 联系入口不遮挡主导航、主要操作或页面内容。

## 3. 范围与边界

### 3.1 本期范围

- 面向已登录用户显示统一的“联系我们”浮动按钮。
- 卡片标题明确为“加入 NeuRun 内测交流群”，避免把二维码误解为一对一客服。
- 桌面端支持 hover、键盘 focus 和点击；触屏端支持点击。
- 提供二维码预览、保存原图和识别失败提示。

### 3.2 非本期范围

- 不建设在线客服、工单、聊天或消息通知系统。
- 不采集用户微信身份、扫码结果或群聊内容。
- 未登录的登录/注册页面暂不展示群二维码，避免公开扩散群邀请。

## 4. 交互规则

### 4.1 入口

入口使用固定在页面右下方的“联系我们”按钮。手机端位于底部主导航上方并避开安全区；
桌面端位于视口右下角。按钮触控区域不小于 44 × 44 px，并提供可见的键盘焦点状态。

### 4.2 桌面端

- 鼠标 hover 或键盘 focus 时立即预览联系卡片。
- 点击按钮后卡片保持打开，便于把鼠标移入卡片扫码或保存图片。
- 点击页面外部或按 `Escape` 关闭；关闭后焦点返回触发按钮。
- 鼠标离开时，只关闭未被点击锁定的临时预览。

### 4.3 触屏端

- 点击按钮打开联系卡片，不依赖 hover。
- 卡片展示完整二维码与“保存二维码”操作。
- 辅助文案说明：长按或保存图片后，可在微信“扫一扫”中从相册识别。
- 再次点击按钮、点击卡片外部或按 `Escape` 关闭。

### 4.4 二维码状态

- 卡片提示二维码可能定期更新，识别失败时刷新页面后重试。
- 二维码不可用时显示明确的“二维码暂不可用，请稍后重试”，不得展示破图图标。
- 二维码本身不包含用户运动、账号或登录凭据。

## 5. 验收标准

1. 登录后的同步、日报详情、日报列表、我的和设置页面都能看到同一联系入口。
2. 320 px 宽手机上，按钮和卡片不遮挡底部导航，不产生横向滚动。
3. 支持 hover 的桌面设备可临时预览并点击锁定；触屏设备单击即可打开。
4. 键盘用户可以打开、操作、关闭卡片，按钮正确维护 `aria-expanded`。
5. 桌面二维码可直接扫描；手机用户可以打开或保存原图后从相册识别。
6. 替换服务端二维码文件后，入口 URL 和页面代码无需变化。
7. 未登录页面不展示或返回群二维码。
