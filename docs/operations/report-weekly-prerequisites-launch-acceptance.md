# 报告中心空状态与周复盘前置链路上线验收

- **适用范围**：报告页“日报 / 周复盘”二级页、日报归档列表，以及用户显式生成周复盘时的逐日事实准备、逐日训练分析和质量课汇总。
- **目标**：页面没有无内容的视觉模块；周复盘使用完整、可回放的逐日事实与训练分析；质量课被稳定提取并可解释，同时不把一次周复盘放大为七次额外在线 AI 请求。
- **数据边界**：只统计服务端任务终态、版本化单日事实、逐日分析状态、周复盘引用、质量课结构化条目和匿名/受控的页面事件。页面文案、完整 Prompt、AI 原始响应、1Hz 明细、Authorization 和密钥不得进入运营导出或日志。
- **口径原则**：首个完整自然周只建立基线，不预设行业指标或增长目标。所有分子、分母、排除原因可回放至 `user_id + week_id + report_id + fact_version`；未采集一律标为“无法判定”。

## 1. 用户可见验收

1. 当日报、周复盘或日报归档没有可显示内容时，页面只保留一个有明确动作或说明的空状态；隐藏状态栏、空容器和折叠内容不得保留高度、边框、阴影或可聚焦元素。
2. 周复盘仅在用户显式生成/刷新时启动。系统先为该自然周内每个已观测日期准备或复用 `TrainingDayFact`、`SessionSummaryFacts` 与确定性训练结构分析，再汇总为周事实；不要求用户先手工生成历史日报，也不自动新建七份可见日报归档。
3. 若已有同一 `fact_version` 的逐日语义分析，可复用；缺失、超时、容量拒绝或 Provider 不可用时，周复盘仍使用确定性逐日分析和事实缺口完成，不得把“AI 不可用”伪装为“没有训练”。
4. 质量课仅从可追溯的训练结构与强度证据中提取。每条至少可说明日期、活动、类别、判定置信度/依据、距离/时长及可用的配速、心率、步频、步幅或分段粒度；缺字段明确省略或标注不可得，不能填零。没有质量课时整个“质量课总结”区隐藏，不显示空卡。

## 2. 成功指标与统计口径

### 2.1 空模块可见率

```text
空模块可见率 = 自动页面检查中，具有可见盒模型但无可见文本、加载态、错误态或可操作控件的报告模块数 /
               自动页面检查的报告模块总数
```

- 覆盖“日报”“周复盘”、有报告/无报告、折叠归档详情与日报列表分页末页。
- `hidden` 元素、关闭的 `details` 内容和空列表容器必须不计入可见模块总数。
- 上线阻断：任何抽样页面存在空白状态栏、空卡片或关闭详情仍占位；文字为空但带有确定加载骨架的短暂加载态单列，不计为静态空模块。

### 2.2 周复盘前置事实完备率

```text
前置事实完备率 = 周复盘范围内状态为 completed_rest、available 或明确 gap 的日期数 /
                 周复盘范围内已观测日期数
```

- `available` 表示可读取、版本匹配的 `TrainingDayFact` 和确定性训练分析；无活动仅在覆盖完成时可为 `completed_rest`。
- `gap` 必须携带 Provider/覆盖/字段原因，属于可解释的完成降级；`unknown`、解析失败、版本漂移或缺少日期锚点不计分子。
- 同时报准备来源：`reused`、`generated`、`deterministic_fallback`、`gap`、`failed`，以及 `fact_version` 漂移数。
- 上线阻断：周复盘引用的日期缺少状态、日期偏移、读取到不同版本的活动集合，或把未知日期当作休息日。

### 2.3 质量课提取可解释率

```text
质量课可解释率 = 有质量课结构化条目且每条均包含活动引用、类别、判定依据/置信度和至少一个可用量化指标的周数 /
                 含至少一条质量课候选的已完成周复盘数
```

- 分类别统计间歇、节奏、阈值、变速和其他已定义类别；“长距离”是否属于质量课以产品合同为准，不得在运营侧自行合并。
- 同报候选数、确认提取数、因低置信度排除数、缺分段/心率/步频/步幅数和 `unsupported` 数。
- 质量课不存在的完整周记为 `no_quality_session`，不进入该指标分母，也不等同于提取失败。
- 上线阻断：质量课无活动证据、把缺失值写为 0、或低置信度/非质量训练被高置信度标为质量课。

### 2.4 周复盘时延与 AI 调用放大

```text
周复盘端到端时延 = 从 accepted 到 completed/failed 的总耗时
每周在线 AI 调用数 = 此周复盘请求关联的实际在线模型调用数
逐日复用率 = reused 的逐日分析数 / 已观测日期数
```

- 每个用户显式周复盘默认至多一次周级在线解释请求；逐日准备、质量课提取和事实汇总必须为本地确定性计算或复用已落盘的同版本结果。
- 逐日语义分析若产品后续允许在线补充，必须独立受容量与缓存控制，不能在一次周复盘中无界地触发七次调用；本次上线验收将任何“周级 1 次 + 每日额外 N 次”视为调用放大事故。
- 维持现有报告任务的总时限/终态契约；按 `accepted`、`running`、`completed_ai`、`completed_deterministic`、`timeout`、`capacity_rejected`、`failed` 分组，不把确定性降级算成失败。

## 3. 最小可观测字段

周复盘任务与其逐日前置记录至少关联：`request_id`、`user_id`、`week_id`、本地周范围、`facts_cutoff`、日期、`fact_version`、准备来源与终态、缺口分类、质量课候选/提取分类、实际 AI 调用计数、各阶段耗时和最终报告 ID。页面检查至少记录路由、Tab、空状态类别和断言结果；不得记录完整报告正文或个人原始运动序列。

没有这些字段时，可做手工抽样验证，但不得发布覆盖率、调用放大或质量课准确率结论。

## 4. 上线与回填策略

1. **新生成周复盘**：按自然周的所有已观测日准备/复用前置事实；同一事实版本幂等复用，事实变更才生成新版本。不会自动生成、覆盖或重写用户既有日报归档。
2. **历史已归档周复盘**：保持其原始事实版本和正文，不静默回填或改写。用户显式刷新时才按当前事实版本重建，并保留新旧报告的版本关联。
3. **存量缺少逐日分析**：生成可回放的确定性前置分析或明确 gap；不为回填而批量调用 AI，不以批处理形式修改用户报告。
4. **异常降级**：某日摘要不可读时，将该日作为有原因的 gap 进入周复盘；若共享事实版本漂移、活动日期错误或质量课证据不可追溯，停止宣布通过，升级为数据契约问题。

## 5. 上线当天清单与风险处置

- 用受控账户或夹具检查日报、周复盘、空日报列表、无周报及关闭的归档详情：无静态空模块，唯一空状态的说明和操作可见。
- 抽样一周包含质量课、一周只有轻松跑/休息、一周含 `limited`/Provider 缺口：核对七日准备状态、`fact_version`、质量课依据和周复盘引用。
- 回放一次已有逐日事实的周复盘：确认逐日均为 `reused` 或确定性汇总，实际在线 AI 调用数不超过一次。
- 模拟一日摘要失败、AI 超时/容量拒绝和质量课低置信度：周复盘进入明确终态、保留可用确定性结论与 gap，不生成空模块或错误质量课。
- 连续首个完整自然周每日检查空模块、前置事实、质量课与调用计数；出现任一上线阻断立即停止扩大使用，保留既有报告，优先降级为确定性周复盘并由开发定位版本/模板问题。

## 6. 验收结论模板

记录统计窗口、页面/周样本、空模块检查结果、前置事实来源分布、质量课候选与排除原因、实际 AI 调用数、端到端耗时、事实版本范围、回填动作（应为无自动改写）和未解决风险。未采集字段、未触发入口或 Provider 不支持时写“无法判定”或“N/A”，不得补猜成功率。
