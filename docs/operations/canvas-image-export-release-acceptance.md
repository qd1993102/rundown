# 浏览器 Canvas 图片导出迁移发布验收

- **适用范围**：Web 内日报图片保存、日报/周复盘分享卡 PNG 导出，以及为这些能力安装、启动或配置 Playwright/Chromium 的发布步骤。
- **目标**：由已登录 Web 页面的浏览器 Canvas 生成 PNG，服务端不再为 Web 图片导出安装或运行 Playwright/Chromium；既有报告 JSON 数据契约不变，图片数据不回传服务端。
- **数据范围**：仅统计受控账户或测试夹具的页面行为、脱敏导出事件和发布产物。不得记录 PNG 内容、完整报告正文、原始运动序列、Authorization、Cookie 或密钥。
- **非目标**：不以本次发布推断 CLI/MCP 的静态日报图片能力已经替代；不新增第三方分享、落地页或用户触达。

## 1. 发布前必须确认的边界

### 1.1 可以保持稳定的契约

Web 端继续复用已鉴权获取的 `GET /api/dashboard` 和 `GET /api/reports/weekly` JSON。字段、鉴权、错误语义和报告日期口径在迁移前后保持一致；Canvas 仅改变浏览器内的 PNG 生成方式。

移动端仍优先使用 Web Share API，桌面端或不支持文件分享的浏览器仍下载 PNG。用户取消系统分享属于可恢复的正常结果，不算导出失败。

### 1.2 需要产品/技术负责人决策的契约

浏览器 Canvas 不能在 CLI、MCP 或无浏览器的服务端运行。当前仓库事实是：`generate_image` 仍是 MCP/CLI 图片导出能力，`/api/reports/share-card/daily` 与 `/api/reports/share-card/weekly` 当前仍返回服务端生成的 PNG，且 `scripts/deploy-ecs.sh` 为此安装 `[image]`、Playwright 和 Chromium。

因此，下列目标不可在未作额外技术替代的情况下同时成立：

1. 删除所有 Playwright/Chromium 运行时依赖；
2. 保持 CLI/MCP/服务端 PNG 接口仍可生成相同图片；
3. 图片生成只使用浏览器 Canvas。

发布前必须由主 Agent 确认以下其中一种范围，并将结果同步到产品、设计、README、MCP 定义和变更日志：

- **Web-only（推荐）**：Canvas 覆盖 Web 日报保存和分享卡；删除仅为这些 Web 能力存在的服务端图片端点/MCP 分享卡工具及其浏览器安装。CLI/MCP `generate_image` 的保留或替代不属于本次删除范围。
- **全量移除浏览器依赖**：同时为 CLI/MCP 静态报告 PNG 选择非浏览器替代实现，或经过兼容期后正式废弃其 PNG 输出。仅删除依赖、但不提供兼容结果，不得称为“接口保持稳定”。

未作该决策时，不得删除 `[image]` extra、`PLAYWRIGHT_BROWSERS_PATH`、部署脚本浏览器安装段或相关系统库安装。

## 2. 用户可见验收

1. 有跑步活动的日报和周复盘均能在当前浏览器生成 PNG；日报、周复盘分享卡满足 [产品方案 — 分享卡](../product/share-card.md) 的数据省略、主题、尺寸和品牌验收标准。
2. 休息日或无跑步活动时不生成分享卡，页面给出明确提示；不发起服务端截图请求。
3. Web Share API 可用时交给系统分享；不可用、被取消或保存失败时，页面恢复可操作状态并提供准确状态反馈。下载回退文件可打开、宽度为 1125px，内容未截断。
4. 主题切换后导出的 Canvas 与当前主题一致；在受支持的移动和桌面浏览器中，长文本、多活动日、无步频、无 AI 结论、无质量课等省略情形均不重叠、不截断。
5. 导出全过程不新增网络请求上传 PNG 或报告内容；浏览器开发者工具网络记录中不得出现新的服务端截图请求。

## 3. 契约与依赖验收

### 3.1 数据/API 回归

对相同测试夹具，在迁移前后分别读取日报和周复盘 JSON，核对：HTTP 状态、鉴权行为、报告日期、跑步活动集合、距离/时长/配速、`actual_summary`、`quality_sessions`、`ai_insight` / `finding` 的存在和空值语义。允许新增仅供前端确定性渲染使用的可选字段；不得修改既有字段含义、以零值替代缺失，或让 Canvas 反向影响报告事实。

对于明确保留的接口，运行现有调用方的契约测试并记录请求、状态码、响应类型和关键字段。对于明确废弃的服务端 PNG 端点或 MCP tool，发布说明必须提供版本、生效时间、替代入口和可机器识别的废弃/错误响应；不能静默返回 HTML、空文件或无解释的 500。

### 3.2 依赖删除证据

在候选 release 中记录以下扫描结果，而不是只依据容器体积或一次成功导出判断完成：

- Python 依赖与锁定/安装产物中没有仅为 Web Canvas 导出保留的 `playwright`；
- 部署脚本不再安装 `[image]`、Chromium、浏览器系统库或中文字体，除非它们已被确认服务于仍保留的非 Web 图片能力；
- systemd unit 和部署环境不再注入仅供已删除路径使用的 `PLAYWRIGHT_BROWSERS_PATH`；
- 服务启动、`/healthz`、日报/周复盘 JSON 读取和 Canvas 导出均不依赖浏览器二进制存在；
- CI/E2E 使用 Playwright 作为测试工具可以保留，但必须与生产运行时依赖分离，不能因此恢复生产 Chromium 安装。

若 CLI/MCP 图片导出仍依赖 `src/image.py` 或其他浏览器渲染器，其依赖、部署配置和风险必须单独列为“保留项”，不可伪报为全量移除。

## 4. 指标与口径

首个完整发布观察窗口只建立基线，不设行业阈值，也不从缺失数据推断成功率。所有事件按 `release_sha + route + export_kind + client_capability + outcome` 聚合；用户标识使用可轮换的受控标识或不记录。

```text
Canvas 生成成功率 = 成功获得 PNG Blob 的导出尝试数 / 已开始 Canvas 导出的尝试数
分享交接率       = 已成功调用系统分享入口的次数 / 支持文件分享且 PNG Blob 成功的次数
下载回退成功率   = 已触发下载且页面未报告保存错误的次数 / 不支持或未完成系统分享后的回退尝试数
服务端截图请求数 = Web 图片导出期间命中服务端截图端点的请求数
```

- `cancelled_share` 单列，既不计入系统分享成功，也不计为 Canvas 生成失败。
- 浏览器拒绝下载、Blob 编码失败、Canvas 安全异常、字体/图片资源异常和未支持能力分别计数；未采集时写“无法判定”。
- 隐私泄露检查不使用自动成功率替代：每个发布候选人工审阅至少一张日报和一张周复盘 PNG，确认不含睡眠、HRV、恢复评分、ACWR、训练建议或原始身份信息。
- 上线阻断：任何 Web 导出命中已声明移除的服务端截图路径；核心报告 JSON 契约漂移；PNG 包含禁止字段；候选服务因缺少 Chromium/Playwright 无法启动；或保留接口出现无替代的不可读结果。

## 5. 上线清单与应急预案

1. 在候选 release 执行全量单元测试、API 契约测试和桌面/移动浏览器 E2E；记录浏览器、视口、主题、报告夹具、文件宽度和导出结果。
2. 在不安装 Chromium、且未设置 `PLAYWRIGHT_BROWSERS_PATH` 的运行环境进行启动与核心 API 冒烟验证。若该变量仍因独立 CLI/MCP 能力保留，必须在交付记录中说明调用方和移除计划。
3. 发布后以受控账户完成日报及周复盘各一次分享/下载路径，检查网络、脱敏事件、文件尺寸与禁止字段；记录统计窗口和原始分子/分母。
4. Canvas 渲染故障时，不回退为服务端截图或上传报告内容。页面保留报告阅读和明确的失败提示，记录脱敏错误分类；仅在已确认保留的旧服务端能力仍受支持时，按其既有契约单独处理。
5. 若报告 JSON 契约、隐私规则或服务可用性发生回归，停止扩大发布并回滚到上一个健康 release。回滚后复核 `/healthz` 的 release SHA、核心 JSON 和 Web 导出；不回写用户报告或导出文件。

## 6. 发布结论模板

记录：发布 SHA、已确认的范围决策、保留/移除的图片接口清单、生产依赖扫描结果、测试浏览器与夹具、JSON 契约回归、各指标原始分子/分母、PNG 隐私审阅结果、服务端截图请求数、回滚演练结果和剩余风险。未执行或未采集的项必须写“未验证/无法判定”，不得标记为通过。
